# Retrieve the narrative algorithm description for LEAD/PAD

Direct access to the `lead_pad_v1` component of `spec_ascvd`. Equivalent
to `get_ascvd_defs(component = "lead_pad_v1", ...)`.

## Usage

``` r
get_lead_pad_v1_defs(...)
```

## Arguments

- component:

  Not used (fixed to `"lead_pad_v1"`); included only because it is
  inherited from
  [`get_ascvd_defs()`](https://perisphere-rwe.github.io/peridefs/reference/get_ascvd_defs.md).
