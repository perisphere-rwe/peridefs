# Retrieve the narrative algorithm description for stroke (any)

Direct access to the `stroke_v1` component of `spec_ascvd`. Equivalent
to `get_ascvd_defs(component = "stroke_v1", ...)`.

## Usage

``` r
get_stroke_v1_defs(...)
```

## Arguments

- component:

  Not used (fixed to `"stroke_v1"`); included only because it is
  inherited from
  [`get_ascvd_defs()`](https://perisphere-rwe.github.io/peridefs/reference/get_ascvd_defs.md).
